AI Content Agent

A three-agent system that runs the content for a TikTok account, and the dashboard the agents report into.

View source

The problem

Making short-form content every day is what kills most accounts.

The research is slow, the scripting is slow, and nobody goes back afterwards to work out which posts did anything. I ran a trading community before and could never keep on top of it.

What I built

Three agents, each with one job.

  • Research finds outliers: videos that beat their creator's own baseline by a wide margin. It scores them and works out the pattern behind each one.
  • Scripting drafts from those patterns: hooks, full scripts, and the variables worth testing between versions.
  • Performance grades what went out. It measures every post against a 1,278-view baseline on a log scale, and the grade feeds back into what gets researched next.

The dashboard sits on top: 18 ranked ideas with the research behind each one, 67 posts tracked, 12 written learnings, and a library of every system document the agents run on.

The version linked here is a read-only snapshot. The live one has database subscriptions and AI drafting tools. In the snapshot I inlined the data, intercepted the write buttons and switched drafting off. One HTML file, no build step, no backend.

Stack

  • Single-file HTML
  • Python build script
  • Vercel

Result

The live system runs the content for @ceotalks23.

The snapshot holds 17 outliers, 8 patterns and 25 creator baselines. It does not update.
