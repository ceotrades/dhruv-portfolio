GEMINI

A pre-market dashboard I built for myself and use every morning.

View live site View source

The problem

Everything I needed before the open lived in a different place.

News in one tab, the economic calendar in another, my own notes in a file. Pulling it together took forty minutes, and I kept skipping it.

What I built

One screen with the news, the economic calendar and a trade journal. It calls the Claude API to read and summarise, so I don't have to scan headlines myself.

It installs to my phone's home screen as a PWA.

Stack

  • React from a CDN, no build step
  • Single HTML file
  • Claude API
  • PWA manifest
  • Vercel

One file on purpose: no framework, no bundler, nothing to maintain.

Result

Morning prep went from forty minutes to ten.
